# 轻食日记 PWA（iPhone 版）

一个手机优先、无需账号和后端的静态网页应用。饮食、体重和目标存储在当前浏览器的本地存储中。AI 食物照片估算通过用户主动切换到 ChatGPT 完成，再把返回的 JSON 粘贴进网页。

## 功能
- 每日饮食记录：早餐、午餐、晚餐、加餐
- 热量、蛋白质、碳水、脂肪汇总
- 自定义每日热量目标
- 体重记录、近 7 天简单统计
- ChatGPT 照片估算提示词 + JSON 粘贴导入
- JSON 备份与导入
- PWA 清单、离线缓存、iPhone 主屏幕图标

## 发布到 GitHub Pages（免费静态托管）
1. 在 GitHub 创建一个新的 public repository，例如 `qing-shi-diary`。
2. 把本文件夹里的所有文件上传到仓库根目录（不要只上传 zip）。
3. 打开仓库 **Settings → Pages**。
4. 在 **Build and deployment** 中选择 **Deploy from a branch**，Branch 选 `main`，文件夹选 `/(root)`，保存。
5. 等待 GitHub Pages 发布，打开它给出的 `https://...github.io/.../` 地址。
6. 在 iPhone 上用 **Safari** 打开该 HTTPS 地址。点分享按钮 → **添加到主屏幕**。如果出现“作为网页 App 打开”选项，可启用后添加。

## 使用 AI 照片估算
1. 在网页中点“打开 AI 录入助手”并复制提示词。
2. 切换到 ChatGPT，上传食物照片并发送提示词。
3. 复制 ChatGPT 返回的 JSON。
4. 回到网页，粘贴并解析。导入后请核对食物、份量、餐次和营养值。

## 隐私与限制
- 不需要登录，不配置服务器，不会自动把饮食记录上传到任何后台。
- AI 照片估算必须联网，并且照片会发送给你选择的 AI 服务。
- 浏览器本地存储并非永久备份。清理 Safari 网站数据、卸载/重置或设备故障可能造成数据丢失；请定期点“导出备份”。
- 离线可使用已缓存的网页和记录功能，但首次打开、首次安装、更新缓存需要网络。
- 热量和营养素是估算值，尤其外卖、炒菜、酱料和不清晰照片会有较大误差。
- 这是初版原型，不提供医学诊断或个性化医疗建议。

## 本地预览
需要通过本地 HTTP 服务预览 PWA 功能；直接双击 `index.html` 可以查看页面，但 Service Worker 离线缓存不会正常工作。
